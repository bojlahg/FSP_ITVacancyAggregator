### 12. Приглашения и отклики без блокировок и уникальности

### 13. Новый push в `master` отменяет уже идущий деплой

Место: [.github/workflows/ci.yml:9-11](../../.github/workflows/ci.yml#L9). Workflow-уровневый `concurrency`
с `cancel-in-progress: true` отменяет весь прогон, включая джобу `deploy` посреди `docker compose up -d --build`;
джобовая группа `deploy-prod` от этого не защищает. При нескольких агентах в `master` это реальный сценарий
полуобновлённого прода. Исправление: `cancel-in-progress: ${{ github.event_name == 'pull_request' }}`.

### 14. Ежедневный бэкап при ошибке `pg_dump` пишет «backup ok» и удаляет старые копии

Место: [infra/scripts/backup.sh:32](../../infra/scripts/backup.sh#L32). Вызов `backup || echo ...` отключает
`set -e` внутри функции (проверено в `sh`), поэтому после упавшего `pg_dump` выполняются `mv`, ротация
`find -delete` и «backup ok». Через несколько дней сбоев остаются только битые дампы. Режим `once` (перед
`reseed`) не затронут. Исправление: `|| return 1` после каждой команды, ротация — только после проверки дампа
(`pg_restore -l`).

- Исправления первого ревью: блокировки попытки на всех изменяющих путях (4 параллельных старта → 1×201 + 3×409),
  приоритет источника навыка, шорт-лист вне окрестности, подтверждение истёкшей категории, отзыв доступа удалённого

- Движок: EAP, 3PL-информация, правило решения, MST и экспозиция соответствуют §10; детерминирован по seed,
  не импортирует БД и FastAPI.

- Score и объяснение — из одних округлённых компонентов `evaluate`; профиль без ФСП теряет только документированный
  вес 0,01; грейд и категория — только из теста.
- IDOR: чужие приглашения, отклики, задания, потребности, челленджи, интеграции и апелляции → 404;
  admin/expert-роуты закрыты ролями; `/admin/reseed` требует admin и `DEMO_MODE`, `/debug/*` — `DEBUG_TOOLS`.
- Auth: argon2id, JWT HS256 на 15 мин, ротация refresh с обнаружением повторного использования, httpOnly-cookie;
  OIDC ФСП с PKCE, state, nonce и проверкой по JWKS; вебхуки — только https и публичные IP, без редиректов.
- Секреты: полная история (159 коммитов) просмотрена — реальных ключей нет, только намеренные dev/demo-значения.
- Фронтенд: нет произвольных hex и шрифтов, серверное состояние только через TanStack Query и сгенерированный
  клиент, access-токен только в памяти, у новых экранов есть состояния загрузки, пустоты и ошибки.
